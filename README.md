# BELLONIX ALM (Advanced Logic Masters) — Корпоративний сайт

Корпоративний веб-сайт компанії **BELLONIX ALM**, яка займається розробкою та впровадженням інтелектуальних систем автоматизації: Telegram/Viber логістичних ботів, інтерактивних аналітичних дашбордів управління в реальному часі та комплексних прокатних рішень.

## 🚀 Функціонал сайту
- **Інтерактивний симулятор екосистеми**: віртуальний телефон водія з імітацією бота, інтегрований із живою аналітичною панеллю керівництва (працює на `Chart.js`).
- **Світла та темна теми**: підтримує автоматичне визначення системної теми користувача та ручний перемикач з динамічним оновленням оформлення графіків.
- **Калькулятор розрахунку вартості**: інтерактивний інструмент для швидкої оцінки бюджету проекту залежно від вибраних модулів.
- **Шаблони та матеріали**: розділ для скачування прикладів робіт (схеми інтеграцій, звітність).
- **Адаптивний дизайн**: оптимізовано під мобільні пристрої, планшети та десктопи.

## 🛠 Технології
- **Frontend**: HTML5, CSS3 (Vanilla CSS, Glassmorphism), JavaScript (ES6)
- **Бібліотеки**: [Chart.js](https://www.chartjs.org/) (для побудови дашбордів), FontAwesome (іконки)
- **Дизайн**: Кольорова гама на базі фірмового логотипу Bellonix ALM.

## 💻 Локальний запуск
Для перегляду сайту запустіть локальний сервер у папці з проектом:
```bash
python3 -m http.server 8000
```
Після чого відкрийте в браузері: `http://localhost:8000`
