2. Webhook API Payload Specification

Events from bots are processed using JSON formatting. Basic payload schema submitted to BAS:

{ "event_id": "evt_98247192847", "timestamp": "2026-07-05T13:40:00Z", "driver": { "telegram_id": 1931242904, "name": "Kovalenko A.", "phone": "+380670000000" }, "location": { "latitude": 50.4501, "longitude": 30.5234, "speed_kmh": 62 }, "status": "IN_PROGRESS", "payload": { "trip_id": "TRIP-101", "odometer": 142850, "comment": "Trip started. Pre-trip check passed." } }

3. Core Integration Benefits

  • NO 1C LEGACY The ecosystem runs entirely on open web APIs configured for modern BAS ERP and BAS Trade Management systems.
  • Low Latency WebSockets enable dashboard state sync under 1.2 seconds from driver action.
  • Fault Tolerance If BAS is offline, the Bellonix gateway queues transaction logs in Redis, performing automatic synchronization immediately upon connection recovery.
