Схема інтеграції: Telegram Bot + BAS CRM

Ця специфікація описує архітектуру обміну даними в реальному часі між месенджер-ботами та корпоративною обліковою системою BAS через проміжний аналітичний сервер Bellonix.

1. Архітектурна діаграма потоку даних

2. Специфікація API Webhook

Для передачі подій від бота використовується формат JSON. Базовий Payload запиту на сторону BAS:

{ "event_id": "evt_98247192847", "timestamp": "2026-07-05T13:40:00Z", "driver": { "telegram_id": 1931242904, "name": "Коваленко О. М.", "phone": "+380670000000" }, "location": { "latitude": 50.4501, "longitude": 30.5234, "speed_kmh": 62 }, "status": "IN_PROGRESS", "payload": { "trip_id": "TRIP-101", "odometer": 142850, "comment": "Початок маршруту. Авто перевірено." } }

3. Ключові переваги інтеграції

  • БЕЗ 1С Система повністю переведена на відкриті стандарти взаємодії з сучасними конфігураціями BAS ERP та BAS Управління Торгівлею.
  • Низька затримка Використання WebSockets дозволяє бачити зміни на дашборді менш ніж за 1.2 секунди після відправлення даних водієм.
  • Автономність У разі тимчасової відсутності зв'язку з BAS, сервер Bellonix накопичує чергу транзакцій у Redis та проводить синхронізацію відразу після відновлення каналу.
